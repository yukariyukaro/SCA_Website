# 优化首屏加载体验计划

## 核心目标
1.  **消除白屏**：在 React 启动前（JS 下载期间）立即显示 Loading 动画。
2.  **优化字体加载**：防止 Google Fonts 阻塞页面渲染。
3.  **加快资源加载**：通过代码分割减小首屏 JS 体积。

## 执行步骤

### 1. 修改 `index.html` (关键路径优化)
我们将直接在 HTML 中注入 Loading 状态，使其成为“首屏内容”。

-   **添加 `<link rel="preconnect">`**: 提前与 `fonts.googleapis.com` 和 `fonts.gstatic.com` 握手，减少字体下载延迟。
-   **注入内联 Loading**: 在 `<div id="root">` 内部添加纯 HTML/CSS 实现的 Loading 动画（复用现有的品牌色和呼吸效果）。这样浏览器一解析完 HTML 就会显示 Loading，无需等待 JS。
-   **优化 Font Awesome**: 使用 `media="print" onload="this.media='all'"` 技巧，使其异步加载，不阻塞渲染。

### 2. 修改 `vite.config.js` (构建优化)
-   **配置 `manualChunks`**: 将 `react`、`react-dom`、`react-router-dom`、`swiper` 等大型依赖拆分为独立的 Vendor Chunk。这能利用浏览器缓存，并可能提升 HTTP/2 的并行下载效率。

## 预期效果
-   用户打开网页后，**立即**看到 Loading 动画，不再有长时间白屏。
-   字体加载即使慢，也不会阻塞 Loading 动画的显示。
-   React 启动后，无缝替换 Loading 动画为应用界面。
