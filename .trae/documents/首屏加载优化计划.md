# 优化首屏加载与 Loading 动画方案

为了解决 Google Fonts 阻塞导致的白屏问题，并确保 Loading 动画最先显示，我将执行以下优化：

## 1. 核心策略：内联 Critical Loading (关键加载)
目前的 Loading 动画是在 React 代码加载并执行后才渲染的 (`main.tsx`)。如果 JS 文件或字体 CSS 加载慢，用户就会看到白屏。
**解决方案**：直接将 Loading 动画的 HTML 和 CSS **写在 `index.html` 里面**。
*   **优点**：浏览器下载完 `index.html` (通常几 KB) 就能立刻显示动画，无需等待 JS、字体或图片。
*   **机制**：React 启动后会自动接管 `#root` 节点，清空里面的静态 Loading 内容并渲染真实应用。

## 2. 辅助策略：优化字体连接
Google Fonts 需要先连接 `fonts.googleapis.com` (获取 CSS)，再连接 `fonts.gstatic.com` (下载字体文件)。
**解决方案**：
*   添加 `<link rel="preconnect">` 标签，告诉浏览器提前与这两个域名建立连接（DNS 解析 + TCP 握手 + TLS 协商），减少后续请求的延迟。

## 具体代码变更

**文件**: `d:\works\SCA_Website\index.html`

1.  **添加 Preconnect**:
    ```html
    <link rel="preconnect" href="https://fonts.googleapis.com">
    <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
    ```

2.  **内联 Loading 样式** (在 `<head>` 中):
    ```html
    <style>
      /* 简单的居中 Loading 样式，使用品牌色 */
      #initial-loader {
        position: fixed;
        top: 0;
        left: 0;
        width: 100%;
        height: 100%;
        display: flex;
        justify-content: center;
        align-items: center;
        background-color: #ffffff;
        z-index: 9999;
        transition: opacity 0.5s ease-out;
      }
      .spinner {
        width: 40px;
        height: 40px;
        border: 4px solid #f3f3f3;
        border-top: 4px solid #A45A52; /* 品牌色 */
        border-radius: 50%;
        animation: spin 1s linear infinite;
      }
      @keyframes spin {
        0% { transform: rotate(0deg); }
        100% { transform: rotate(360deg); }
      }
    </style>
    ```

3.  **内联 Loading 结构** (在 `<body>` 的 `#root` 中):
    ```html
    <div id="root">
      <div id="initial-loader">
        <div class="spinner"></div>
      </div>
    </div>
    ```
